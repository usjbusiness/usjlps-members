# Обновление печати My USJ — v2, с недельной сеткой

## Установка
1. Сделайте резервную копию проекта.
2. Скопируйте папки `src` и `tests` из архива в корень проекта с сохранением путей. Подтвердите замену `src/pages/MyUSJ.tsx` и `src/planner.css`. Остальные исходные файлы новые.
3. Выполните `npm ci` (если зависимости ещё не установлены), затем `npm run build`.
4. Опубликуйте собранный проект обычным способом.

SQL, миграции Supabase, изменения .env и новые зависимости не требуются. Это патч для переданного архива usjlps-members-main.zip, а не полный проект. Если после его передачи эти два существующих файла менялись, сначала сопоставьте изменения, не заменяйте их вслепую.

## Использование
В My USJ → Semester Planner нажмите **Print / Save PDF** рядом с кнопкой добавления курса.
- Выберите текущий план, все планы или несколько планов галочками.
- При необходимости добавьте подпись каждому плану, имя студента и заметку адвайзору.
- Выберите портретную или альбомную ориентацию.
- Нажмите Print / Save PDF и выберите Save as PDF в системном диалоге печати. Для более чистого документа отключите браузерные колонтитулы.

Печатаются только включённые курсы выбранных планов. Каждый план начинается с новой страницы. Сначала выводится наглядная цветная недельная сетка, как в оригинальном интерфейсе: дни по колонкам, время по вертикали, пропорциональная высота блоков и параллельные полосы для пересечений. Подробная таблица начинается со следующей страницы, длинные таблицы продолжаются далее. Номера и цветовые отметки связывают сетку с полной таблицей. Очень короткие и тесные блоки отображаются компактно; при более чем трёх одновременных занятиях используются цветные маркеры без мелких обрезанных надписей — вся информация остаётся в полной таблице. Указаны полное название курса, секция, CRN, преподаватель, все встречи, аудитории и кредиты. Поиск курсов и режим Day/Week не ограничивают документ. При незаполненных данных показывается явная отметка, сведения не придумываются.

Подписи, имя студента и заметка действуют только в открытом окне печати и не меняют сохранённые планы. Обычная печать Ctrl/Cmd+P из вкладки Planner выводит отдельную копию текущего плана без дополнительных подписей. Для нескольких планов используйте кнопку.
